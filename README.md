# MedShop POS — releases

Windows installers and update files for the MedShop pharmacy POS (Datova Systems).

- **Beta channel:** the [`beta` release](https://github.com/Sijodata/medshop-releases/releases/tag/beta).
  Installed counters check `latest.json` there and update themselves; every update is signed and verified by the app.
- Download the newest `MedShop-POS_<version>_x64-setup.exe` from that release to install a new counter.

This repository only holds release files. The source code is private.
